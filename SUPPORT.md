# Support

There is no paid support plan and no service-level agreement for GridSight
today, because there is nothing released to support.

## What exists now

| Need | Where to go |
| --- | --- |
| Status, scope and limits | [`docs/STATUS.md`](docs/STATUS.md) and the product page <https://rezafarsi.com/en/gridsight/> |
| A question about the approach | Open an issue with the `question` template |
| A correction to the documentation | [`CONTRIBUTING.md`](CONTRIBUTING.md) |
| A security concern | [`SECURITY.md`](SECURITY.md) — privately, not in an issue |
| Work that has to happen now | The remote IEC 61850 service: <https://rezafarsi.com/en/services/iec-61850/> |

## The honest version

The engine is being built. The engineering work — SCL review, GOOSE/SV capture
analysis, pre-conformance readiness review — is delivered today as a fixed-scope
remote service, using the project's own scripts and the client's files. If you
need a substation file reviewed this month, that is the route; the product is
not.

## Response expectations

One maintainer, best effort. Issues are usually read within two weeks. Nothing
here creates an obligation to respond within a stated time, and no urgency
claim will be accepted on the basis of this repository.
